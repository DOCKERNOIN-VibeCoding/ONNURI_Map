# 온누리 가맹점 지도

온누리상품권 사용처를 지도에서 한눈에 보기 위한 앱입니다.
**시장·상점가를 지도에 찍고**, 핀을 누르면 그 안의 온누리 가맹점 목록이 뜹니다.
가맹점마다 **네이버 플레이스로 바로 가는 버튼**이 있어 영업시간·리뷰를 확인할 수 있습니다.

- 지도: **카카오맵** (배포 시 무료 한도 부담이 적음)
- 가게 정보: **네이버 플레이스 링크** (리뷰·영업시간·사진은 네이버가 강함)
- 실행 환경: Windows + Python 3.10 이상, 로컬 웹서버 + 브라우저

### 왜 가맹점이 아니라 시장이 지도에 찍히나요

공공데이터의 `소재지` 컬럼에는 **시/도 이름 하나만** 들어 있습니다.
15만 행 전부가 `서울`, `경기` 같은 한 단어라 도로명도 지번도 없습니다.
그래서 가맹점 하나하나의 좌표는 이 데이터만으로 구할 수 없습니다.

대신 `소속 시장명`은 모든 행에 채워져 있고 고유값이 2,698개입니다.
이 시장·상점가의 좌표를 찾아 지도에 찍고, 가맹점은 소속 시장에 묶어 보여줍니다.
없는 좌표를 지어내지 않는 대신, "이 근처에서 온누리를 쓸 수 있는 곳"은 정확히 알 수 있습니다.

## 1. 설치

```powershell
pip install -r requirements.txt
```

## 2. 카카오 API 키 발급

1. https://developers.kakao.com 접속 → 카카오 계정으로 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기**
3. 만든 앱 선택 → **앱 키** 메뉴에서 두 개를 복사
   - **JavaScript 키** → 지도 표시용
   - **REST API 키** → 시장 좌표를 찾는 용도
4. **플랫폼 → Web 플랫폼 등록** → 사이트 도메인에 `http://127.0.0.1:5173` 입력
5. **제품 설정 → 카카오맵 → 활성화 ON**
   (이게 꺼져 있으면 `disabled OPEN_MAP_AND_LOCAL service` 403 이 납니다)

발급받은 키를 넣습니다.

```powershell
copy config.sample.json config.json
notepad config.json
```

> config.json 은 `.gitignore` 에 들어 있어 GitHub에 올라가지 않습니다.
> **REST API 키는 서버용 비밀키입니다.** 채팅·커밋 메시지·스크린샷에 노출하지 마세요.
> 노출되면 developers.kakao.com 에서 재발급하세요.

## 3. 가맹점 데이터 받기

공공데이터포털에서 자동으로 내려받습니다. 로그인도 인증키도 필요 없습니다.

```powershell
python fetch_data.py --import
```

수동으로 받고 싶으면 [데이터셋 페이지](https://www.data.go.kr/data/3060079/fileData.do)에서
CSV를 받아 `data/` 에 넣고 `python import_csv.py data\파일명.csv` 를 실행하면 됩니다.

## 4. 시장 좌표 찾기

2,700곳 남짓이라 몇 분이면 끝납니다.
**먼저 한 지역만 돌려 결과를 확인**한 뒤 전체를 돌리는 걸 권합니다.

```powershell
python geocode_markets.py --sido 서울    # 서울만 먼저 (434곳)
python geocode_markets.py                # 전체
python geocode_markets.py --retry        # 못 찾은 곳만 재시도
```

중간에 Ctrl+C 로 끊어도 됩니다. 다시 실행하면 남은 곳부터 이어서 진행합니다.

## 5. 실행

```powershell
python app.py
```

브라우저가 자동으로 열립니다. (`http://127.0.0.1:5173`)

## 사용법

| 기능 | 설명 |
|---|---|
| 지도 이동/확대 | 화면에 보이는 시장·상점가만 자동으로 불러옵니다 |
| 핀 클릭 | 시장 이름·주소·가맹점 수가 뜨고, **가맹점 보기**를 누르면 왼쪽에 목록이 펼쳐집니다 |
| 가맹점 목록 | 각 가맹점의 **네이버** 버튼으로 네이버 지도 검색 결과가 열립니다 |
| 검색창 | 시장명·가맹점명·품목으로 거릅니다. 시장명이 맞으면 그 시장 전체가 나옵니다. Enter를 누르면 첫 결과로 지도가 이동합니다 |
| 지류 / 디지털 | 해당 상품권을 받는 가맹점이 있는 시장만 남깁니다 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `fetch_data.py` | 공공데이터포털에서 최신 CSV 자동 다운로드 |
| `import_csv.py` | CSV → SQLite 적재 (시장 / 가맹점 분리 저장) |
| `geocode_markets.py` | 시장·상점가 좌표 찾기 (카카오 로컬 API), 중단/재개 가능 |
| `app.py` | 로컬 웹서버 (Flask). 지도 화면과 조회 API |
| `onnuri_db.py` | SQLite 스키마와 설정 로딩 |
| `static/` | 지도 화면 (HTML/CSS/JS) |
| `onnuri.db` | 데이터 (git에 올리지 않음) |
