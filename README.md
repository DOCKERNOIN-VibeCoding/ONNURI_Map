# 온누리 가맹점 지도

온누리상품권을 들고 나가서 **어디서 먹을지 고를 때** 쓰라고 만든 앱입니다.
멀리서 보면 **시장·상점가**가 찍히고, 확대하면 **가맹점 하나하나**가 찍힙니다.
가맹점 핀은 **식당(주황)과 그 외(회색)**로 나뉘고, `식당만` 을 켜면 식당만 남습니다.
식당은 **한식·중식·회·고기구이** 같은 **12개 종류**로 다시 거를 수 있습니다.
가맹점마다 **네이버 플레이스로 바로 가는 버튼**이 있어 영업시간·리뷰·별점을 확인할 수 있습니다.

- 지도: **카카오맵** (배포 시 무료 한도 부담이 적음)
- 가게 정보: **네이버 플레이스 링크** (리뷰·영업시간·사진은 네이버가 강함)
- 실행 환경: Windows + Python 3.10 이상, 로컬 웹서버 + 브라우저

### 왜 가맹점이 아니라 시장이 지도에 찍히나요

공공데이터의 `소재지` 컬럼에는 **시/도 이름 하나만** 들어 있습니다.
15만 행 전부가 `서울`, `경기` 같은 한 단어라 도로명도 지번도 없습니다.
그래서 가맹점 하나하나의 좌표는 이 데이터만으로 구할 수 없습니다.

대신 `소속 시장명`은 모든 행에 채워져 있고 고유값이 2,698개입니다.
이 시장·상점가의 좌표를 찾아 지도에 찍고, 가맹점은 소속 시장에 묶어 보여줍니다.
없는 좌표를 지어내지 않는 대신, "이 근처에서 온누리를 쓸 수 있는 곳"은 정확히 알 수 있습니다.

## 1. 설치

```powershell
pip install -r requirements.txt
```

## 2. 카카오 API 키 발급

1. https://developers.kakao.com 접속 → 카카오 계정으로 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기**
3. 만든 앱 선택 → **앱 키** 메뉴에서 두 개를 복사
   - **JavaScript 키** → 지도 표시용
   - **REST API 키** → 시장 좌표를 찾는 용도
4. **플랫폼 → Web 플랫폼 등록** → 사이트 도메인에 `http://127.0.0.1:5173` 입력
5. **제품 설정 → 카카오맵 → 활성화 ON**
   (이게 꺼져 있으면 `disabled OPEN_MAP_AND_LOCAL service` 403 이 납니다)

발급받은 키를 넣습니다.

```powershell
copy config.sample.json config.json
notepad config.json
```

> config.json 은 `.gitignore` 에 들어 있어 GitHub에 올라가지 않습니다.
> **REST API 키는 서버용 비밀키입니다.** 채팅·커밋 메시지·스크린샷에 노출하지 마세요.
> 노출되면 developers.kakao.com 에서 재발급하세요.

## 3. 가맹점 데이터 받기

공공데이터포털에서 자동으로 내려받습니다. 로그인도 인증키도 필요 없습니다.

```powershell
python fetch_data.py --import
```

수동으로 받고 싶으면 [데이터셋 페이지](https://www.data.go.kr/data/3060079/fileData.do)에서
CSV를 받아 `data/` 에 넣고 `python import_csv.py data\파일명.csv` 를 실행하면 됩니다.

## 4. 시장 좌표 찾기

두 단계로 나뉩니다. **공식 주소가 있는 전통시장부터** 처리하고, 남은 곳을 이름으로 찾습니다.

```powershell
python market_address.py                 # ① 전통시장: 공식 주소 → 좌표 (정확)
python geocode_markets.py                # ② 나머지: 이름 검색 (추정)
```

①은 세 가지를 차례로 씁니다.

1. 소상공인시장진흥공단의 **전통시장현황 · 골목형상점가현황 · 상점가현황** 에서 주소를 가져와
   주소로 좌표를 찍습니다. 이름만 검색하는 ②보다 정확합니다.
2. 그래도 못 찾은 곳은 **온누리상품권 공식 사이트**(onnuri.gift)가 공개하는 시장 목록의
   좌표로 메웁니다. 이 목록에는 시/도가 없어서, 좌표의 행정구역을 되짚어 우리 데이터의
   시/도와 같은지 확인한 뒤에만 씁니다.

①이 처리한 시장은 ②가 건드리지 않습니다.
전통시장만 쓰면 골목형상점가·음식문화거리가 통째로 빠지므로 세 자료를 모두 봅니다.

②는 2,700곳 남짓이라 몇 분이면 끝납니다.
**먼저 한 지역만 돌려 결과를 확인**한 뒤 전체를 돌리는 걸 권합니다.

```powershell
python geocode_markets.py --sido 서울    # 서울만 먼저
python geocode_markets.py --retry        # 못 찾은 곳만 재시도
```

중간에 Ctrl+C 로 끊어도 됩니다. 다시 실행하면 남은 곳부터 이어서 진행합니다.

### (선택) 가맹점 개별 좌표

```powershell
python store_coords.py
```

[상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do)에서 상호명이 같고
**소속 시장 반경 500m 안에 있는** 가게를 찾아 가맹점 좌표를 채웁니다.
전국 가맹점의 약 52%(76,161곳)가 찍히고, 그 중 27,670곳이 식당으로 분류됩니다.
336MB 를 내려받으므로 처음 한 번은 시간이 걸립니다.
반경 안에 동명 가게가 둘 이상이면 어느 쪽인지 알 수 없으므로 **비워둡니다**(약 1%).
이걸 돌리지 않으면 지도는 시장 단위로만 동작합니다.

## 5. 실행

```powershell
python app.py
```

브라우저가 자동으로 열립니다. (`http://127.0.0.1:5173`)

## 사용법

| 기능 | 설명 |
|---|---|
| 지도 이동/확대 | 화면에 보이는 것만 자동으로 불러옵니다 |
| **확대(레벨 5 이하)** | 시장 핀이 **가맹점 핀**으로 바뀝니다. 주황=식당, 회색=그 외. 한 건물에 여러 곳이면 숫자로 묶입니다 |
| 시장 핀 클릭 | 시장 정보가 뜨고, **가맹점 보기**를 누르면 **두 번째 패널**이 옆으로 펼쳐집니다 |
| 두 번째 패널 | 그 시장의 가맹점이 **식당 먼저, 그 외 나중**으로 나옵니다. 업종이 함께 표시되고, 좌표를 아는 가게를 누르면 지도가 그 자리로 갑니다 |
| 가맹점 핀 클릭 | 그 자리의 가게 목록이 업종과 함께 뜹니다 |
| 가맹점 목록 | 각 가맹점의 **네이버** 버튼으로 네이버 지도 검색 결과가 열립니다 |
| 검색창 | 시장명·가맹점명·품목으로 거릅니다. 시장명이 맞으면 그 시장 전체가 나옵니다. Enter를 누르면 첫 결과로 지도가 이동합니다 |
| 식당만 | 업종이 '음식'으로 확인된 가맹점만 남깁니다. 업종은 상권정보로 확인된 가맹점에만 있어서, `store_coords.py` 를 돌려야 켜집니다 |
| **식당 종류** | 한식 · 분식·간식 · 고기·구이 · 카페·디저트 · 회·해산물 · 치킨·피자·버거 · 주점 · 중식 · 양식 · 일식 · 아시안 · 기타 중에서 고릅니다. 고르면 자동으로 식당만 남습니다 |
| 지류만 가능한 곳 제외 | **기본으로 켜져 있습니다.** 디지털(모바일·카드) 온누리가 안 되는 가맹점 13,942곳(9.5%)을 뺍니다. 지류를 쓰실 때만 끄면 됩니다 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `fetch_data.py` | 공공데이터포털에서 최신 CSV 자동 다운로드 |
| `import_csv.py` | CSV → SQLite 적재 (시장 / 가맹점 분리 저장) |
| `market_address.py` | 공식 시장·상점가 목록에서 주소·좌표를 가져와 시장 좌표 채우기 |
| `geocode_markets.py` | 나머지 시장·상점가 좌표 찾기 (이름 검색), 중단/재개 가능 |
| `store_coords.py` | (선택) 상권정보로 가맹점 개별 좌표 찾기 |
| `app.py` | 로컬 웹서버 (Flask). 지도 화면과 조회 API |
| `onnuri_db.py` | SQLite 스키마와 설정 로딩 |
| `static/` | 지도 화면 (HTML/CSS/JS) |
| `onnuri.db` | 데이터 (git에 올리지 않음) |
