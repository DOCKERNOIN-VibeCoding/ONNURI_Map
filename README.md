# 온누리 가맹점 지도

온누리상품권 사용처를 지도에서 한눈에 보기 위한 앱입니다.
공공데이터포털의 전국 온누리상품권 가맹점 데이터를 지도 위에 뿌리고,
가맹점을 클릭하면 **네이버 플레이스로 바로 이동**할 수 있습니다.

- 지도: **카카오맵** (배포 시 무료 한도 부담이 적음)
- 가게 정보 확인: **네이버 플레이스 링크** (리뷰·영업시간·사진은 네이버가 강함)
- 실행 환경: Windows + Python 3.10 이상, 로컬 웹서버 + 브라우저

---

## 1. 설치

```powershell
pip install -r requirements.txt
```

## 2. 카카오 API 키 발급

1. https://developers.kakao.com 접속 → 카카오 계정으로 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름: 아무거나, 예: `온누리지도`)
3. 만든 앱 선택 → **앱 키** 메뉴에서 두 개를 복사
   - **JavaScript 키** → 지도 표시용
   - **REST API 키** → 주소를 좌표로 바꾸는 용도
4. **플랫폼 → Web 플랫폼 등록** → 사이트 도메인에 `http://127.0.0.1:5173` 입력
   (이걸 빠뜨리면 지도가 안 뜹니다)
5. **카카오맵** 사용 설정을 켭니다 (제품 설정 → 카카오맵)

발급받은 키를 넣습니다.

```powershell
copy config.sample.json config.json
notepad config.json
```

> config.json 은 `.gitignore` 에 들어 있어 GitHub에 올라가지 않습니다.
> 키 값을 README나 커밋 메시지에 쓰지 마세요.

## 3. 가맹점 데이터 받기

1. 공공데이터포털 [소상공인시장진흥공단_전국 온누리상품권 가맹점 현황](https://www.data.go.kr/data/3060079/fileData.do) 접속
2. **다운로드** 버튼으로 CSV 내려받기 (로그인 불필요, 약 12만 건)
3. 받은 파일을 `data/` 폴더에 넣고 적재

```powershell
python import_csv.py data\받은파일명.csv
```

## 4. 주소를 좌표로 변환 (지오코딩)

공공데이터에는 좌표가 없고 주소만 있어서, 한 번 변환해 두어야 합니다.
**먼저 한 지역만 돌려보고** 잘 되면 전체를 돌리는 걸 권합니다.

```powershell
python geocode.py --sido 서울특별시     # 서울만 먼저
python geocode.py                       # 전체 (시간이 꽤 걸립니다)
```

- 중간에 Ctrl+C 로 끊어도 됩니다. 다시 실행하면 이어서 진행합니다.
- 변환 결과는 주소 기준으로 캐시되어 같은 주소를 두 번 호출하지 않습니다.

## 5. 실행

```powershell
python app.py
```

브라우저가 자동으로 열립니다. (`http://127.0.0.1:5173`)

## 사용법

| 기능 | 설명 |
|---|---|
| 지도 이동/확대 | 화면에 보이는 가맹점만 자동으로 불러옵니다 |
| 검색창 | 상호명 · 시장명 · 취급품목으로 걸러냅니다. Enter를 누르면 첫 결과로 지도가 이동합니다 |
| 지류 / 디지털 | 상품권 종류별 가맹점만 표시합니다 |
| 마커 클릭 | 상호·시장·주소·취급품목과 **네이버 플레이스** 버튼이 뜹니다 |
| 왼쪽 목록 | 항목을 누르면 해당 가맹점으로 지도가 이동합니다 |

너무 축소하면 마커 대신 안내 문구가 뜹니다. 전국 12만 개를 한 번에 그리면
브라우저가 버티지 못하기 때문입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 로컬 웹서버 (Flask). 지도 화면과 조회 API |
| `import_csv.py` | 공공데이터 CSV → SQLite 적재 |
| `geocode.py` | 주소 → 좌표 변환 (카카오 로컬 API), 중단/재개 가능 |
| `onnuri_db.py` | SQLite 스키마와 설정 로딩 |
| `static/` | 지도 화면 (HTML/CSS/JS) |
| `onnuri.db` | 데이터 (git에 올리지 않음) |
